# Arquivo histórico

Documentos preservados por assunto e origem. Datas, “atual”, PASS, GO, homologações, comandos e caminhos nos relatórios pertencem aos respectivos cortes; não especificam o contrato vigente nem autorizam operações. O RC.4 é uma distribuição histórica, distinta da branch atual.

Os arquivos abaixo foram movidos sem renomear os relatórios. O diário da Demo foi extraído de `examples/live-demo/NOTES.md` para separar instruções atuais de observações antigas. Somente destinos de hyperlinks relativos afetados pela mudança foram ajustados; narrativas, resultados e ressalvas históricas foram preservados. Os links para código apontam aos caminhos no checkout atual, não fixam os bytes antigos: consulte a referência de versão de cada relatório.

Não foram importados os logs/capturas externos. Caminhos absolutos de máquina, nomes de artefatos ausentes e referências textuais antigas foram conservados como parte do registro; não prometem disponibilidade pública nem são instruções de execução atuais.
